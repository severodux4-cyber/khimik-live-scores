# Химик live scores — GitHub Actions

Бесплатный вариант мониторинга:
ФХМО → GitHub Actions → Telegram.

Проверка запускается по субботам и воскресеньям каждые 5 минут с 9 утра до 19:00.
На первом запуске состояние создаётся без уведомлений, затем отправляются только изменения счёта.

## Secret
В репозитории GitHub:
Settings → Secrets and variables → Actions → New repository secret

Name:
BOT_TOKEN

Value:
токен Telegram-бота от BotFather.

Токен не помещать в код и не коммитить в GitHub.

## Важно
Парсер сделан устойчивым к небольшим изменениям HTML, но перед боевым использованием нужно проверить первый запуск GitHub Actions и его логи. Если структура ФХМО изменилась, селекторы можно быстро поправить.
