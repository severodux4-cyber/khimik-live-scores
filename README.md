# Химик live scores — GitHub Actions

Навайбкодил бота, он парсит и отслеживает результаты с сайта ПМО

Далее, присылает сюда - @Khimik2017ScoresBot

Принцип такой: он берёт матчи из всех групп с 2010 по 2017 годов, где есть Химик, отслеживает результаты в реальном времени и в случае изменения, отсылает в бот.

с 2010 - 2016 отслеживаются и присылаются счета только Химик

2017 - все счета в первой группе.

То есть - будут уведомления о изменениях в счете и затем финальный счёт.
